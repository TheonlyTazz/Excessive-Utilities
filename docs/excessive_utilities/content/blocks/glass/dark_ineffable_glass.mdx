**Ineffable Glass (Dark)** is a glass block.

Non-sneaking players can pass through this block, while mobs cannot. Sneaking makes the block solid to the player. It also prevents light from passing through it.

This block supports connected textures when [Athena](https://www.curseforge.com/minecraft/mc-mods/athena) is installed. Athena is also available on [Modrinth](https://modrinth.com/mod/athena-ctm).
